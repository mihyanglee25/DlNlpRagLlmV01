서브워드 토크나이저(Subword Tokenizer)

희귀어와 미등록어 문제를 완화하는 서브워드 토큰화 기법을 정리합니다.

이 페이지의 설명은 원문 전체 복제가 아니라 공개 목차를 기반으로 학습 목적에 맞게 재서술한 요약입니다. 예제 코드와 원문의 상세 설명은 WikiDocs에서 확인합니다.
13-01

바이트 페어 인코딩(Byte Pair Encoding, BPE)

빈번하게 함께 등장하는 문자 또는 기호 쌍을 반복적으로 병합해 서브워드 어휘를 만드는 방식입니다. 희귀어 문제와 어휘 크기 사이의 균형을 잡습니다.

학습 포인트개념 정의 → 작동 원리 → 장단점 → 실제 NLP/LLM 적용 위치의 순서로 이해하면 좋습니다.
13-02

센텐스피스(SentencePiece)

문장을 사전 분절하지 않고 원시 문자열에서 직접 서브워드 모델을 학습합니다. 다양한 언어를 동일한 방식으로 다루기 좋습니다.

학습 포인트개념 정의 → 작동 원리 → 장단점 → 실제 NLP/LLM 적용 위치의 순서로 이해하면 좋습니다.
